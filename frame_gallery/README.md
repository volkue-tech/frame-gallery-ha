# Frame Gallery

Fresh artwork on your Samsung Frame — from Home Assistant, with one tap.

![Actual Frame Gallery dashboard: colourful geometric artwork by Theo van Doesburg, a tap-to-load preview and optional artwork information.](https://raw.githubusercontent.com/volkue-tech/frame-gallery-ha/main/docs/images/dashboard-commons.png)

- Choose 1000 curated near-widescreen works from Wikimedia Commons, museum artwork from the Art Institute of Chicago or Cleveland Museum of Art, or your own JPEG/PNG images. No API key is needed. Commons is first/default on new installations; updates retain your saved source.
- For Commons, optionally choose one colour. It must occupy a noticeable part of the work, not necessarily the largest area. `any` keeps all colours. The other sources remain available but do not apply this colour wish.
- From b7, optionally choose a Commons artist, alone or combined with colour. Use an offered catalogue label/key; other sources report this filter as ignored.
- Show the whole work without cropping by default. Previously sent works are skipped while new eligible works remain.
- Start from the app page, an automation, or an optional dashboard card with a preview of the latest successful upload.
- Optionally add title, artist and museum below the preview with built-in cards and one Text helper; the standard card stays minimal.
- Install on Home Assistant OS, including Green. No SSH, Docker setup, HACS, or edits to `configuration.yaml`.

**First start:** enter your TV's fixed private IPv4 address in **Configuration**, save, keep **Watchdog off**, and start the app with the TV on. Accept the TV's connection prompt within 20 seconds. With **Background mode off** (the default), the app stops after each run by design.

**Next:** open the **Documentation** tab for the setup guide and complete dashboard examples. The dashboard is not installed automatically. Setup is available in [English](https://github.com/volkue-tech/frame-gallery-ha/blob/main/frame_gallery/DOCS.md#installation), [Deutsch](https://github.com/volkue-tech/frame-gallery-ha/blob/main/frame_gallery/SETUP.de.md) | [Français](https://github.com/volkue-tech/frame-gallery-ha/blob/main/frame_gallery/SETUP.fr.md) and [Español](https://github.com/volkue-tech/frame-gallery-ha/blob/main/frame_gallery/SETUP.es.md) | [Italiano](https://github.com/volkue-tech/frame-gallery-ha/blob/main/frame_gallery/SETUP.it.md).

**For Commons:** select `wikimedia_commons`, keep Landscape only on and Image fit `contain`. Sources are within 2.5% of 16:9; leave Prefer 16:9 on for the closest matches or turn it off for the whole curated selection. Small margins can remain, without cropping. Your existing dashboard still works. See the [collection and rights notes](https://github.com/volkue-tech/frame-gallery-ha/blob/main/frame_gallery/COMMONS.md).

**Public beta 0.1.0b13 — startup/send handoff.** The optional automatic initial read waits for a fixed ten-second window. An accepted new-artwork command takes priority and consumes the remaining initial opportunity, even if the send fails or returns `no_match`; no leftover startup read follows. Without an accepted send, standalone initial synchronization remains available with valid cached HA on; later genuine off-to-on recovery is unchanged. This bounded window cannot anticipate arbitrarily delayed scripts: a later send must first stop an already running receiver. Existing cards, scripts and per-TV memory stay compatible. See the [b13 validation report](https://github.com/volkue-tech/frame-gallery-ha/blob/main/BETA13_VALIDATION.md) and [matching sources](https://github.com/volkue-tech/frame-gallery-ha/releases/tag/sources-v0.1.0b13) for exact release checks. The offline-proven startup pattern is fixed, but the cause of the physical switch into TV mode is not proven; no new hardware/no-wake guarantee is claimed. A connection may still wake the TV or affect its mode. Update without uninstalling.

**Historical b12 release:** the following records the earlier initial-sync feature and its checks.

**Public beta 0.1.0b12.** Optional initial synchronization when this TV's configured Samsung HA entity already says on at app start; no new image or off/on cycle. Missing/off/unknown/invalid/error consumes that initial opportunity; duplicate on does not retry it. Later fresh off-to-on recovery remains. Fresh TV/Art Mode/ID/image proof is required. Existing cards, per-TV memory, filters and dependencies stay compatible. Native ARM/Intel validators and actual publisher images, matching sources, four verified evidence archives, anonymous pulls/imports and independent signatures passed; see the [validation report](https://github.com/volkue-tech/frame-gallery-ha/blob/main/BETA12_VALIDATION.md). No new TV/sleep or universal no-wake guarantee: a connection may wake a TV or affect its mode. Update without uninstalling.

**Optional current-TV artwork (b12):** [event-based current title and artist](https://github.com/volkue-tech/frame-gallery-ha/blob/main/frame_gallery/CURRENT_ARTWORK.md), with complete five-language guides and no extra dashboard extension/helper. A successful send saves the per-TV artwork association. One connection then listens to supported slideshow events without periodic TV queries. Optionally configure the existing Samsung HA entity: first cached on at startup and later fresh off-to-on transitions permit bounded read-only revalidation, without another image send. Unknown old images remain unidentified. Experimental and off by default: a connection may wake the TV or affect its mode. Existing cards work with the mode off; their preview/caption still means last delivered, not a live TV image. Initial/slideshow confirmation expires after 90/900 seconds; a static image can become unconfirmed without new proof.
